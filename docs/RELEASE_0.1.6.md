# 0.1.6 — 扫描图片、段落与网址页脚

状态：Windows x64 和 Mac arm64 最终包已分别构建并完成实际验收。干净源码已公开到 GitHub；本轮预编译 ZIP、离线资源包和完整源码 ZIP 在本机交付，未上传 GitHub Release 附件。首次验收发现 Windows 路径分隔符使缓存快照为空，已修正并要求所选页的原始缓存必须存在，随后两平台完整重测、重建和重验。以下均为修正后的最终结果，首轮候选及原始记录仅在本机保留。

## 本轮范围

- 保留扫描封面和正文中的小图形，使用 PDF 原像素裁切，并记录来源。已烧录在封面或插图中的文字属于图像，不涂抹、不生成替代图片。圆形注释标记作为原图保留，不据外观擅自建立注释链接；邻近 OCR 可能重复识别其字符，仍需报告和校对。
- 段落整理使用 OCR 四角坐标测量真实字高和倾斜方向，再结合行距、缩进、对齐及标点判断连接。源坐标与逐行文本保留，几何分析不改写文字。跨页合并只采用充分的版面证据，不保证复杂扫描的全部段落自动恢复。
- 重复推广网址按页脚识别。需要至少三页提供独立底边小字、相同网址及相近位置的证据；网址路径不同、正文网址、编号脚注、缺乏几何信息或来源混合时保持保守。没有针对某本书或某个网站的删除名单。
- 从任务已有的原始识别结果重新整理版面，不重新加载 OCR / GPU 模型。重新整理保留原始缓存，人工修订按来源核对；无法可靠匹配时保留为冲突，不静默覆盖。

## 已验证的局部结果

- 页脚规则的六项新合成几何回归及一项既有边缘规则回归通过，共 7 项。覆盖旧版误标的脚注 / 标题、倾斜长行的真实字高、协议 OCR 变体、至少三页证据门槛，以及合法网址、人工修改、缺失和异常坐标等反例。这些测试不冒充真实 OCR 准确率。
- 对本地已有识别缓存进行了只读复核：重复网址页脚在关闭保留选项时从导出正文省略，开启时进入运行页脚计划；原始识别和页面缓存的摘要、修改时间保持不变。新段落来源中的多边形坐标也已交叉验证。用户材料及其提取内容仅保存在本机私有目录，不收入源码、测试样本或公开仓库。
- 公开发布准备脚本只选择源码、锁定依赖、对应第三方源码和自制样本；不选入任何本机验收目录。公开源码 ZIP 使用 `--no-evidence`，同样排除所有机器特定记录；私有目录即使额外指定也会拒绝。干净源码已公开到 [Kyusho9/local-pdf-to-epub](https://github.com/Kyusho9/local-pdf-to-epub)，应用 ZIP 本轮在本机交付。

## 最终源码与发布包验收

- Mac：完整工程测试 **128 项通过，49.50 秒**，测试期间源码摘要不变。原生 Cocoa 冻结 GUI 和后台进程在内核拒绝全部网络条件下通过混合文档转换、取消恢复、人工修订、页边开关、页码确认 / 撤销，以及选页重新整理。重整检查实际包含 4 个原始缓存文件和 3 个未选页文件；摘要与修改时间不变，人工修订保留。五个实际产物通过 EPUBCheck 5.4.0，零错误、零警告；归档解压、严格 ad-hoc 签名及清洁环境启动检查通过。
- Windows：完整工程测试 **127 项通过、1 项跳过，225.53 秒**。跳过的 `test_standalone_worker_rejects_other_platform_without_cloud` 专门检查非 Windows 平台拒绝运行 Windows worker，不适用于本机；实际 GPU 协议另有目标平台验收。新版独立解包后的 686 文件与 ZIP 全部一致，旧 0.1.5 同样 686 文件保持逐字节一致。清洁 PATH / ASCII 环境的冻结 CLI 启动通过。DirectML 原生冻结 GUI 在真实单程序出站防火墙阻断下通过转换、取消恢复、修订和重新整理；网络探针实际返回 10013，阻断前后正控可连接，结束后本轮规则和任务全部清理，不声称 Windows 回环也被阻断。重整检查实际包含 4 个原始缓存文件和 3 个未选页文件，摘要与修改时间不变，人工修订保留。两个 GUI 产物通过 EPUBCheck，零错误、零警告。
- 两平台构建记录中的全部 **33 项生产源码**和 **39 项阅读器及对应源码资源**与冻结源文件一致。GPU 运行包继续使用此前已校验的固定版本，没有修改全局驱动或 CUDA Toolkit。
- 额外抽样：在独立的六页私有副本上，用最终 Windows 冻结 CLI 重整，实际保留 1 幅原封面、4 个正文小图；188 份原始识别缓存的摘要与修改时间及修订文件摘要均不变，182 页排除状态保留，修订冲突为 0，未初始化 OCR，EPUBCheck 通过。命令返回 2，明确这是部分结果，没有冒充整书完整转换。用户材料及原始报告不进入 GitHub 或源码 ZIP。
- 验证边界：全新 Windows 系统、其他 Mac 系统版本与更多显卡型号仍未覆盖，不能把清洁 PATH 等同于全新系统。Mac 包未经 Developer ID 签名和公证；软件及模型在其他书籍上的文字准确性仍需校对。
