# 0.1.1：页眉页码与报告改进

本次针对用户在Windows混合样本中的反馈：重复页眉页码进入正文，同类疑点重复出现，EPUB转换说明直接展示了机器JSON。

## 已实现

- 文档组装时识别有跨页证据的重复页眉页脚和数字页码，仅从预览和EPUB正文中排除。所有块、原始提取、坐标和原页仍保留；不擅自改写正文。
- 「正文处理」提供自动判断、保留在正文、从正文排除。人工改文默认保留；明确人工排除仍有效。重新识别后原文或来源变化，旧决定保留为冲突，当前内容安全保留。
- 待核对内容按相同提示合并页码；已替换坏文字层、已将图片文字重排单列为处理记录。EPUB不再显示原始JSON，外置报告保留完整原始疑点与每个排除块的理由。
- 旧任务可以直接重新导出。没有改动解析后端、模型、OCR参数或逐页缓存版本，因此无需重新OCR。

## 边界

规则保守，只处理小字号几何特征、短单行、窄页边区域且多页证据一致的内容。不同章名页眉、罗马页码等可能继续保留，用户可人工排除。没有声称自动清理任意PDF，也没有降低扫描内容需核对的提示。Windows干净系统、代码签名等首版验证边界仍然适用。
